# Code of Conduct

All participants in the Goliath project are expected to uphold the following principles:

1. **Respect** – Treat others with courtesy and professional demeanor.
2. **Inclusivity** – Encourage diverse viewpoints and backgrounds.
3. **Integrity** – Be honest about contributions and errors.
4. **Accountability** – Own mistakes, learn, and fix promptly.
5. **Collaboration** – Share knowledge and help newcomers.

Violations may lead to a formal review and possible removal from the project. For guidance, see the [Contributor Covenant](https://www.contributor-covenant.org/).
